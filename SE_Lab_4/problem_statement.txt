SE LAB 04: Catch the falling object Game, LLM-assisted Bug Fixing


PROBLEM STATEMENT
-----------------

Use an LLM assistant to find and fix bugs in a small Python/Pygame game
called "Catch-falling". Record the game before and after the fixes.

FILES IN THIS FOLDER
--------------------

1. before_implementation_game.mp4
   Screen recording (about 10 seconds) of the original version. The player
   moves a paddle/basket around and catches objects to raise the score. This
   version has only a score counter, with no lives, timer or obstacles.

2. after_implementation_game.mp4
   Screen recording (about 16 seconds) of the corrected version. It adds:
     - A lives counter (5 lives).
     - multiple balls falling for the user to Catch.
     - longer paddle for the user.
     - Increase in speed to do some justice for the user.
     - A "Round Over / Final Score / Press R to Restart" screen

3. LLM_Chat_Link.txt
   A shared link to the LLM conversation used to find and fix the issues.



PROJECT STRUCTURE SEEN IN THE RECORDINGS
----------------------------------------

Modules: main.py, game_engine.py, player.py, coin.py, collection.py,
renderer.py, and requirements.txt. Built with Python 3.12 and Pygame 2.6.1.
(The source code is not in this folder.)

NOTE ON GAME UPDATE
-------------------
I have updated the game vastly adding multiple assets, backgrounds and 2 balls 
to juggle (the ball bounces of the paddle at the angle of incidence) at a time 
for 3 times at which point the ball breaks, therefore increasing the game score,
the game also has a point multiplier, extra lives that fall from the ceiling, 
and many more. you can try it out on itch.io .
